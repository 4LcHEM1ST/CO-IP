4. Факторизация рациональной функции и единственность множителей.

8. Факторизация функции, близкой к единице в норме Винера.

## Работа с рукописью

Сохранён порядок тем. Для логарифма явно указан непрерывный выбор
вдоль пути; в действительной части восстановлены знаки модуля.
Формула через приращение логарифма не требует дифференцируемости.

На странице 4 исправлено обозначение подалгебры для обратной функции:
$(1-\beta/t)^{-1}\in W_-$ при $|\beta|<1$. В доказательстве факторизации
внутренние и внешние корни обозначены разными буквами. Постоянный
коэффициент включён в $a_+$, что даёт нормировку $a_-(\infty)=1$.

Для оценок в банаховой алгебре явно добавлено условие $\|e\|=1$.
Формальное сокращение бесконечных рядов заменено переходом к пределу
в конечном телескопическом тождестве. Сохранён порядок множителей
в доказательстве устойчивости обратимости: коммутативность там не нужна.

В последней подписи исходника стоит $\operatorname{ind}(1+d)=0$;
она согласована с рассматриваемой функцией $1-d$. При $\|d\|_W<1$
оба варианта имеют нулевой индекс.

## Дополнения и границы исходного материала

Теорема Винера приведена без доказательства, как и в рукописи.
Доказательство факторизации рациональной функции не выдаётся за
доказательство факторизации произвольного элемента алгебры Винера.

Развёрнуты доказательства формулы индекса рациональной функции
и единственности множителей при фиксированной степени. Добавлены
пример рациональной факторизации, оценка остатка ряда Неймана,
открытость множества обратимых элементов и оценка изменения обратного.

На последней странице рукописи есть формулировка факторизации $1-d$
и геометрическое пояснение нулевого индекса. Построение множителей
отсутствует. В конспекте оно явно отмечено как дополнение: логарифм
строится сходящимся рядом в $W$, его коэффициенты разделяются
по знакам степеней, затем берутся экспоненты.

Схема области значений $1-d$ выполнена в TikZ внутри `notes.tex`.
Она показывает содержащий образ круг, а не точную форму рукописной кривой.

## Сборка LaTeX

Из этой папки:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error notes.tex
```

Если `latexmk` недоступен:

```bash
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
```

Нужны стандартные пакеты LaTeX, включая `amsmath`, `amsthm`, `babel`
с русским языком, кодировку `T2A`, `geometry`, `hyperref` и `tikz`.
