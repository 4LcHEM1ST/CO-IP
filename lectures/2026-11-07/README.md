## Работа с рукописью

Сохранён порядок доказательства: сдвиги, достаточные условия,
линейные множители, конечные ядра, приближение общего символа.
Сжатия действуют на $X_+=\operatorname{Im}P_+$ с индексами $k\geqslant1$.
На этом пространстве $P_+$ является единицей.

Уточнены знаки степеней сдвига: при $m>0$ левый обратный к $S_m$
и правый обратный к $S_{-m}$ связаны равенством $S_{-m}S_m=I$.
Отсутствие второго обратного объяснено через образ и ядро.

В лемме для $\alpha_0-t$ развернуты все случаи возможной обратимости
граничного оператора. Вторая лемма для $1-\alpha_0/t$, записанная
в рукописи без доказательства, доказана аналогичным возмущением параметра.

Термин «финитный» пояснён как конечность ядра и ленточность матрицы;
он не означает конечного ранга. При выделении линейного множителя
согласованы знаки $t-\alpha_0$ и $\alpha_0-t$. Отдельно объяснено,
почему для левого и правого обратного множитель выделяется с разных сторон.

В общем случае используется исправленное усечение
$b(t)=a_N(t)-a_N(\alpha_0)$: оно точно сохраняет нуль в $\alpha_0$.
Обе части погрешности оценены через хвост ряда. Записанное в рукописи
доказательство для правого обратного распространено на левый
с теми же оценками. Единичный оператор в постоянной поправке
явно обозначен как $I_{X_+}$.

## Дополнения

Из формул сдвигов выписаны точное ядро $S_{-m}$ и равенство
$S_mS_{-m}=I-E_m$. Через факторизацию построены односторонние
обратные к $T_a$ при положительном и отрицательном индексе.

Достаточные и необходимые условия собраны в итоговую таблицу.
Добавлены примеры $t^2$, $t^{-2}$, $2-t$ и $1-t$ для проверки
направлений сдвига и знака индекса. Они отмечены как дополнение.

Схема окрестности точки единичной окружности выполнена в TikZ внутри
`notes.tex`. Это геометрическая иллюстрация возмущения параметра;
отдельных графических файлов для сборки не требуется.

## Сборка LaTeX

Из этой папки:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error notes.tex
```

Если `latexmk` недоступен:

```bash
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
```

Нужны стандартные пакеты LaTeX, включая `amsmath`, `amsthm`, `babel`
с русским языком, кодировку `T2A`, `geometry`, `hyperref` и `tikz`.
