## Содержание

1. Завершение критерия обратимости целочисленного смаза: тождество Безу.
2. Погрешность изображения и обусловленность восстановления.
3. Дробный смаз: символ, веса ядра и доказательство обратимости.
4. Пространства последовательностей на группе целых чисел.
5. Свёртка в $\ell^1(\mathbb Z)$, абсолютная сходимость и оценка нормы.
6. Коммутативность и ассоциативность свёртки.

## Работа с рукописью

Сохранён порядок тем. Обозначения норм и индексов приведены к единому виду.
В доказательстве обратимости дробного смаза развёрнуты суммы синусов
и косинусов, а также завершающий переход: возможный нуль символа требует
`r = 0` или `r = 1`, что противоречит `0 < r < 1`.

В исходной формуле числа обусловленности потерян знаменатель,
зависящий от частоты. В конспекте приведена корректная формула с полными
собственными числами; ошибочное сокращение сохранено в расшифровке
с явной пометкой. Нулевая частота рассмотрена отдельно.

Уточнены смысл 8-битной яркости и оценка погрешности квантования.
Для нормы $\ell^\infty$ дано отдельное определение. Перед перестановкой
бесконечных сумм обоснована абсолютная сходимость; в доказательстве
ассоциативности исправлен промежуточный индекс.

Как дополнения отмечены оценка усиления ошибки, пример плохой
обусловленности обратимого дробного смаза и следствие о банаховой
алгебре. Схема весов дробного смаза выполнена в TikZ внутри `notes.tex`.

## График обусловленности

На странице 2 рукописи есть схематический график с пометкой `N = 720`,
без численной шкалы по вертикали. Дополнительный график в конспекте
рассчитан независимо по собственным числам для `1 ≤ k ≤ 60`.
Он не является оцифровкой рукописного рисунка.

- [`conditioning.pdf`](assets/figures/conditioning.pdf) — векторный график;
- [`conditioning.png`](assets/figures/conditioning.png) — растровая версия;
- [`conditioning.csv`](assets/figures/conditioning.csv) — значения и признак обратимости;
- [`plot_conditioning.py`](assets/figures/plot_conditioning.py) — скрипт расчёта и построения.

На графике показаны только взаимно простые с `720` значения `k`.
Для необратимых матриц в CSV значение числа обусловленности оставлено
пустым, а поле `invertible` равно `False`.

Для повторного построения из папки лекции нужен Python с NumPy и Matplotlib:

```bash
python3 assets/figures/plot_conditioning.py
```

## Сборка LaTeX

Из этой папки:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error notes.tex
```

Если `latexmk` недоступен:

```bash
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
```

Нужны стандартные пакеты LaTeX, включая `amsmath`, `amsthm`, `babel`
с русским языком, кодировку `T2A`, `geometry`, `hyperref` и `tikz`.
Готовый график включён в материалы; для сборки конспекта запускать Python
не требуется.
