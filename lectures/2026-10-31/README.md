## Содержание

1. Определение оператора Винера–Хопфа и матрица сжатия свёртки.
2. Треугольные подалгебры и две леммы о проекторе $P_+$.
3. Факторизация оператора Винера–Хопфа.
4. Обратимость крайних множителей на положительной полуоси.
5. Левые и правые обратные операторы.
6. Степени и произведения односторонне обратимых операторов.
7. Устойчивость односторонней обратимости при малом возмущении.

## Работа с рукописью

Сохранён порядок тем. Алгебры свёрток обозначены $\mathcal C,\mathcal C_\pm$,
чтобы отличать их от двустороннего сдвига $V$. Матричные схемы
переписаны через элементы $a_{k-j}$ и блоки относительно
$X=X_-\oplus X_+$.

Сохранено соглашение $P_+x=(x_k\mathbf1_{k\geqslant1})$:
нулевая координата относится к отрицательной части. Оператор
$T_a=(P_+AP_+)|_{X_+}$ определён на $X_+=\operatorname{Im}P_+$.
Именно на этом пространстве утверждается обратимость крайних множителей;
на всём $\ell^1(\mathbb Z)$ сжатия обнуляют $X_-$.

Леммы о треугольности сформулированы как равенства операторов
на всём двустороннем пространстве и доказаны по координатам.
При вставке проекторов в факторизацию явно указано, какая лемма
применяется. В доказательстве обратимости крайних множителей
проверены оба порядка произведения.

На странице 5 исправлен заключительный вывод «только справа»
на «только слева»: последнее следует из условия и приведённого
доказательства. Порядок множителей в формулах односторонних
обратных сохранён; коммутативность не предполагается.

## Дополнения и границы исходного материала

Самостоятельные случаи из рукописи развёрнуты: вторая лемма,
обратимость положительного крайнего множителя, правосторонние
варианты свойств степеней и произведений, устойчивость обратимости
только справа.

Для пояснения определений добавлены односторонние сдвиги $R,L$:
$LR=I$, $RL=I-E_1$. Они дают примеры обратимости только с одной
стороны и показывают, почему сжатие произвольного произведения
не обязано совпадать с произведением сжатий.

Для возмущённых операторов явно построены односторонние обратные
и добавлены оценки их норм через ряд Неймана.

Последняя строка рукописи — $P_+V^\kappa P_+$. Дальнейшего разбора
центрального множителя в PDF нет. Примеры $\kappa=1,-1$ отмечены
как дополнение; общая классификация не приписывается исходнику.

Матричные и блочные схемы набраны непосредственно в `notes.tex`.
Отдельные графические файлы для сборки не требуются.

## Сборка LaTeX

Из этой папки:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error notes.tex
```

Если `latexmk` недоступен:

```bash
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
```

Нужны стандартные пакеты LaTeX, включая `amsmath`, `amsthm`, `babel`
с русским языком, кодировку `T2A`, `geometry`, `hyperref` и `tikz`.
