## Содержание

1. Оператор свёртки и точное равенство его нормы норме ядра в $\ell^1$.
2. Банахова алгебра операторов свёртки и изометрический изоморфизм.
3. Алгебра Винера, комплексные ряды Фурье и норма.
4. Операции в алгебре Винера и свёртка коэффициентов произведения.
5. Символ оператора и связь трёх алгебр.
6. Индекс непрерывной ненулевой функции на окружности.

## Работа с рукописью

Сохранены порядок тем и основные обозначения. Нормы последовательностей,
функций и операторов различены индексами. Оператор с ядром $a$ обозначен
$A_a$, алгебра таких операторов — $\mathcal C$. Отображление из ядер
в операторы обозначено $\Phi$, чтобы не смешивать его с преобразованием
Фурье из предыдущих лекций.

Развёрнуты доказательства равенства норм, изоморфизмов и полноты алгебр.
Перед группировкой членов произведения рядов обоснована абсолютная
сходимость двойной суммы. Дополнительно доказана однозначность
коэффициентов ряда, на которой основано определение нормы Винера;
для сравнения этой нормы с максимумом модуля функции дан отдельный пример.

Для индекса уточнён непрерывный выбор аргумента вдоль пути, доказаны
целочисленность и независимость от выбора аргумента. Формулы функций
в геометрических примерах добавлены для пояснения: исходные рисунки
не задают конкретных аналитических выражений.

Рукопись заканчивается заголовком «Аналитическая формула индекса»
без самой формулы. В конспекте это явно отмечено. Интегральная формула
приведена как справочное дополнение при дополнительной кусочной
непрерывной дифференцируемости пути; одна принадлежность алгебре Винера
такой гладкости не гарантирует.

Схема изоморфизмов и рисунки для индекса выполнены в TikZ внутри
`notes.tex`; отдельные графические файлы для сборки не требуются.

## Сборка LaTeX

Из этой папки:

```bash
latexmk -pdf -interaction=nonstopmode -halt-on-error notes.tex
```

Если `latexmk` недоступен:

```bash
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
pdflatex -interaction=nonstopmode -halt-on-error notes.tex
```

Нужны стандартные пакеты LaTeX, включая `amsmath`, `amsthm`, `babel`
с русским языком, кодировку `T2A`, `geometry`, `hyperref` и `tikz`.
